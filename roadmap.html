✓ V9.0 — PWA și progres local la revenire

Manifest PWA și service worker pentru încărcarea offline a paginilor deja vizitate, după instalarea cache-ului. ✓ V8.0 — Guvernare autonomă și interfață îmbunătățită

Reparat butonul de activare/dezactivare a pilotului automat din Governor OS (salvare prin fluxul corect). Reparată și confirmarea alertelor critice. Consiliul poate construi automat locuințe sau ferme atunci când există deficit și fonduri suficiente, fără aprobarea Guvernatorului; clădirile obișnuite continuă să fie construite automat. Modul manual oprește construcțiile periodice ale primarului. Orașul are atmosferă luminoasă, fundal îmbunătățit, carduri și contururi rafinate. Rămâne o simulare locală în browser, fără server persistent, AI extern sau notificări push când aplicația este închisă. Necesită testare pe Android.

✓ V7.2 — Notificări critice opționale

Governor OS poate cere permisiunea de notificări a browserului și afișa alerte critice noi prin Notification API. Permisiunea este cerută doar după apăsarea butonului. Alertele continuă să existe în registrul intern și nu se repetă în aceeași sesiune. Limitare: notificările necesită pagina Governor OS deschisă; nu sunt push în fundal, nu funcționează dacă browserul blochează API-ul și nu există încă server persistent. Următorul obiectiv: backend securizat, rulare programată și push real cu abonare explicită.

✓ V7.1 — Guvernare autonomă, notificări critice

Consiliul orașului alege singur politica economică pe baza bugetului, hranei, locuințelor, fericirii și cercetării. Situațiile grave sunt înregistrate ca alerte critice fără duplicate, iar Governor OS permite consultarea și marcarea lor ca văzute. Pilotul automat poate fi activat sau dezactivat. Notificările sunt interne, vizibile numai la deschiderea paginii; nu există încă push pe Android. Sistemul necesită testare pe telefon.

✓ V7.0 — Antreprenori și economie autonomă

Firmele au acum statut activ/închis și pot intra în faliment după trei verificări consecutive cu capital foarte redus. O firmă închisă poate fi redeschisă în condiții economice favorabile. Cetățenii cu economii suficiente pot investi capital propriu și deveni fondatori, apoi primi dividende din surplus. Șomajul afișat este calculat doar pentru cetățenii de vârstă activă. Governor OS afișează firme active, închise și antreprenori. Model economic simplificat; nu există încă o contabilitate completă sau lichidare juridică. Testare Android necesară.

Principii de dezvoltare

Autonomie verificabilă

Fiecare decizie automată trebuie să aibă motiv, efect și intrare în jurnal.

Guvernatorul aprobă

Cheltuielile discreționare și acțiunile externe rămân sub control uman.

Offline-first

Simularea de bază funcționează fără API plătit și fără server.

Salvări compatibile

Versiunile noi trebuie să migreze datele vechi, fără resetare forțată.

Criterii pentru V3

  • Cel puțin 100 de cetățeni simulați pe telefon fără blocaje majore.
  • Vehiculele folosesc drumuri, nu deplasare directă prin clădiri.
  • Orașul se dezvoltă fără intervenție manuală.
  • Salvările vechi V1/V2 rămân compatibile.
  • Jocul funcționează offline; cost API zero pentru baza simulării.
